📐 UML Design & Architecture Patterns

The exact Object-Oriented design implemented behind this working application.

1. Strategy Pattern (Smart Brain)

ParkingStrategy interface implemented by NearestSpotStrategy. Decouples allocation logic from ParkingLot, satisfying the Open-Closed Principle (OCP).

2. Facade Pattern (Entry/Exit)

ParkingLot provides a unified, simple facade (assignSpot, releaseSpot), orchestrating floors, tickets, and strategies.

3. Observer Pattern (Telemetry)

ParkingFloor pushes status events to the DisplayBoard in real time without CPU polling loops.

4. Hierarchical Composition

ParkingLot $\rightarrow$ ParkingFloor $\rightarrow$ ParkingSpot cleanly organizes the multi-level physical garage.
